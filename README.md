# AquaSync
AquaSync: Smart Water Pump Product Platform with Owner Monitoring Portal and Mobile App
## Overview
A full-stack digital twin platform for a smart water pump company.
- **Marketing:** Public product catalog and simulated purchase flow.
- **Digital Twin:** Generates `Device_UUID` upon purchase.
- **Ownership:** Links hardware identity to user accounts via activation codes.
- **Telemetry:** Real-time monitoring via Node.js simulator.
## Tech Stack
- Web: Next.js + Tailwind CSS
- Backend: Node.js + Express
- Database/Auth: Supabase
- Mobile: Flutter
